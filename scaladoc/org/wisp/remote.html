class UdpRouter[K, M <: RemoteMessage[K], R](address: SocketAddress, capacity: Int)(using executor: ExecutionContext, read: ReadWrite[M], write: ReadWrite[R]) extends UdpClient[R], Runnable

UDP-based router that receives remote messages and dispatches them to registered actors.

UDP-based router that receives remote messages and dispatches them to registered actors.

This class manages a UDP server that listens for incoming messages, validates them using CRC32C checksums, deserializes them, and routes them to the appropriate actor based on the message path.

Type parameters

K

the type of the path key used to identify registered actors

M

the type of remote messages

Value parameters

address

the socket address to bind the UDP server to

capacity

the buffer capacity for receiving UDP packets (If capacity is less that bytes that are required to hold the datagram then the remainder of the datagram is silently discarded)

executor

the execution context for asynchronous operations

read

the ReadWrite serializer for message deserialization
