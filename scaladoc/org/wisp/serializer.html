def fromBytes[T](data: Array[Byte], compress: Boolean = ..., offest: Int = ..., length: Int = ...)(using readWrite: ReadWrite[T]): T

Deserializes a value of type T from a byte array with optional compression support.

Deserializes a value of type T from a byte array with optional compression support.

The byte array format is:

  • First byte: compression flag (1 if compressed, 0 if uncompressed)
  • Remaining bytes: the serialized data (either compressed or uncompressed)

Type parameters

T

the type of value to deserialize

Value parameters

compress

whether to check and handle compression

data

the byte array containing the serialized data

length

the number of bytes to read (default: data.length)

offest

the starting offset in the byte array (default: 0)

readWrite

the implicit ReadWrite instance for type T

Attributes

Returns

the deserialized value of type T
