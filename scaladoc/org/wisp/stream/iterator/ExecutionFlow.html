override def next(callback: Option[T] => Unit)(using ec: ExecutionContextExecutor): Unit

Requests the next element from the stream and invokes the provided callback function with a Option instance. The callback will receive either the next element wrapped in Some or None to signify the end of the stream.

Requests the next element from the stream and invokes the provided callback function with a Option instance. The callback will receive either the next element wrapped in Some or None to signify the end of the stream.

Per one next(callback) call, exactly one callback is going to be called with Some or None message.

Value parameters

callback

A function to process the Option received from the stream.

executionContext

An implicit ExecutionContextExecutor used to execute the callback asynchronously.
